من امیررضا مغفوری هستم و این اولین repo من است. این repo نامش intern start است و صرفا یک repo آموزشی است.
فایل ها به این صورت هستند:
hello.py,
quiz.py,
echo-mini.py


hello.py: این فایل از شما دو ورودی میگیرد:
ورودی اول نام شما و ورودی دوم هدف شما.
و هنگامی که شما ورودی‌ها را میدهید این متن را برای شما چاپ میکند:
{نام شما}, every day you get one step closer to:{هدف شما}

quiz.py: این فایل از شما سه سوال می‌پرسد. هر سوالی که شما جواب میدهید یک امتیاز دارد. اگر موفق شوید هر سه سوال را جواب دهید یعنی شما آمادگی کامل دارید. اما اگر موفق نشدید هیچ سوالی را پاسخ دهید، مشکلی نیست شما میتوانید دوباره تلاش کنید.

echo-mini.py: این فایل یک agent کوچک برای شماست که برای شما جمع دو عدد را محاسبه و میتواند برای شما ساعت دقیق را نمایش دهد. برای تجربه بهتر از این agent، شما میتوانید دستور help را وارد کنید تا agent شما را راهنمایی کند.
